\paragraph{Motivating pilots, not primary evidence.}
Development runs on a validation-guided USPTO retrosynthesis compiler and one
repeated Penguin public task showed apparent room for harness-level gains.
They are retained only as
\pilotonly{case studies that motivated typed attribution and sealed evaluation}.
The USPTO candidate involved manual, validation-guided engineering and one
trajectory; the Penguin task has a contemporaneous pure-model reference but no
preregistered matched search-run design, independent replication, or hidden
split.  Neither demonstrates confirmatory automatic self-evolution or supports
the primary comparisons.  An adaptively tuned Symptom2Disease run is expressly
excluded from the main results because its test data were exposed before later
tuning.

No confirmatory result should be inferred from implementation tests, replay
fixtures, or the absence of a crash.  Table~\ref{tab:results} must remain visibly
blocked until every result is linked to the preregistration commit, exact model
and runtime hashes, complete search closures, a signed atomic release, the
prespecified analysis, and a reproducible table source.  The final paper needs
both reliability and sealed-utility results; neither can be selected or extended
after seeing the atomic release.
